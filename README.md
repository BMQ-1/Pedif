## What is Pedif?

**Pedif — PDF Editor** is a complete PDF reader and light editor that lives in one
self-contained HTML file. There is nothing to install and nothing to sign up for:
open the file in a modern browser and it just works — online or offline, on desktop
and mobile.

Everything happens locally on your device. Documents are rendered, searched,
annotated and edited in the browser; no data is ever sent to a server.

---

## Features

**Reading**
- Continuous scroll, single-page and two-page spread modes (spread on wider screens)
- Fit to width, fit to page, or actual size
- Pinch-to-zoom, double-tap-to-zoom, +/− buttons, and reset
- Scrubbable progress bar with a live page bubble
- Thumbnail grid, outline/table of contents, and go-to-page
- Full-text search across every page, with matches highlighted
- Password-protected PDFs

**Annotating**
- Highlight text in four colours (yellow, green, blue, pink)
- Attach notes to any highlight and change its colour later
- Bookmarks (tap the ★, or long-press for the list)
- Highlights &amp; notes list with per-item editing

**Editing**
- Extract any range of pages into a brand-new PDF
- Auto-trim white margins and fine-tune crop by hand
- Rotate the view, print, download a copy, share, or open from a URL

**Comfort**
- Read aloud (text-to-speech) with voice and speed controls
- Light, Dark, Sepia and OLED themes; theme or original page tint
- Screen-brightness dimmer and a screen wake-lock while reading
- Reading statistics
- Full Undo / Redo across highlights, notes, bookmarks, crop and rotation
- iOS-style motion, with respect for *reduce motion*
- Right-to-left and Arabic-aware text layout

**Library**
- A local library with cover thumbnails that remembers every document
- Resume exactly where you left off, in list or grid view
- Manage or clear stored documents at any time

## Quick start

1. Download **`Pedif — PDF Editor.html`**.
2. Double-click it (or drag it into your browser) to open the app.
3. Tap **Open a PDF**, choose a file, and start reading.

That's it — no build step, no dependencies, no network required.

> Tip: To keep Pedif handy, bookmark it, or use your browser's
> **Install / Add to Home Screen** option to use it like a native app.

## Using Pedif

### Opening documents

- **Open a PDF** — tap the drop zone and pick a file.
- **Drag &amp; drop** — drop a PDF anywhere on the home screen.
- **Open from URL** — paste a direct link (Menu → *Open from URL*). The file is
  fetched and opened locally; some servers block cross-origin access.
- **Library** — recently opened documents appear here; tap one to resume.

### Reading &amp; navigation

- Scroll, or switch to **Page** or **Spread** mode from the menu.
- Tap a page to hide or reveal the toolbar and dock.
- **Double-tap** to zoom into a spot; **pinch** to scale; tap **100%** to reset.
- Use the **scrubber** along the top edge to jump through the document.
- Use **Thumbnails** (grid) or **Locate** (go to page) for quick jumps.

### Search

Menu → **Search** (or `Ctrl`/`⌘` + `F`). Type two or more characters to search the
whole document; every match is highlighted on the page. Tap a result to jump to it.

### Highlights &amp; notes

1. Select text on a page.
2. Tap **Highlight**, then choose a colour — or tap **Add note**.
3. Open **Highlights &amp; notes** from the menu to review, edit the note, change the
   colour, jump to the page, or delete.

### Bookmarks

Tap the **★** in the toolbar to bookmark the current page. **Long-press** the ★ to
see all bookmarks and jump between them.

### Table of contents

Menu → **Contents** (or `O`). Uses the document's built-in outline when present.

### Extract pages

Menu → **Extract pages**. Type a range (for example `1-5, 8, 11-13`), use a shortcut
chip (All, This page, Odd, Even, Bookmarked, Invert, Clear), or tap pages to pick
them. The selection is saved as a **new PDF** — your original is untouched.

### Margins &amp; crop

Menu → **Margins &amp; crop**. **Auto-trim** scans the first page for the content
box, or drag the Top / Bottom / Left / Right sliders to trim by hand. The setting
applies to every page of that document.

### Rotate, fullscreen, print, download, share

All under the menu:
- **Rotate view** — turn pages 90° at a time.
- **Fullscreen** — distraction-free reading.
- **Print** — send the document to your printer.
- **Download / Save a copy** — save the file back to your device.
- **Share** — share the file via your device's share sheet.

### Read aloud

Menu → **Read aloud**. Pedif reads the current page using your device's voice, then
continues to the next page automatically. Pick a voice and adjust the speed.

### Themes &amp; appearance

Menu → **Appearance**:
- **Reading mode** — Scroll / Page / Spread
- **Fit** — Width / Page / Actual
- **Theme** — Light / Dark / Sepia / OLED
- **Page tint** — match the theme or keep the original page colours
- **Dim the screen** — an independent brightness control

Cycle themes quickly with `D`.

### Reading statistics

Menu → **Reading statistics** — time spent, pages seen, progress and a time estimate.

### Undo &amp; redo

Every edit — highlights, notes, colour changes, bookmarks, crop and rotation — is
reversible. Use the **↶ / ↷** buttons in the toolbar, the menu, or the keyboard.
A slider drag counts as a single step.

### Library

The home screen keeps a local library of everything you've opened, with covers and
reading progress. Switch between **list** and **grid** views, and use **Manage** to
remove individual documents or clear the whole library.

### Keyboard shortcuts

| Action | Shortcut |
| --- | --- |
| Open search | `Ctrl`/`⌘` + `F` |
| Next page | `J`, `→`, or `Space` |
| Previous page | `K` or `←` |
| Zoom in / out | `+` / `−` |
| Reset zoom | `0` |
| Go to page | `G` |
| Contents | `O` |
| Bookmark | `B` |
| Toggle theme | `D` |

| First / last page | `Home` / `End` |

| Redo | `Ctrl`/`⌘` + `Shift` + `Z` (or `Ctrl` + `Y`) |

## Privacy &amp; offline

Pedif is built to be private by design:

- **No network calls.** There is no backend, no analytics and no telemetry.
- **No uploads.** Files are read and edited entirely in your browser.
- **Offline-first.** Once the file is loaded, it works with no connection at all.

Your library, reading positions, bookmarks, highlights, crop settings and
preferences are stored **locally** in your browser (IndexedDB and `localStorage`).

---

## How it works

Pedif is a single HTML file containing the app, its styles and its engines. There is
no build step and no runtime dependencies.

- **Rendering:** [PDF.js](https://mozilla.github.io/pdf.js/) 3.11 (embedded).
- **Writing / editing:** [pdf-lib](https://pdf-lib.js.org/) (embedded) — powers
  *Extract pages*.
- **Library storage:** an IndexedDB database named `folio` holds document copies and
  metadata.
- **State &amp; preferences:** `localStorage`, namespaced under `fo:` (theme, mode,
  fit, page tint, brightness, reading positions, bookmarks, annotations, crop,
  statistics and a library index).

Because everything is local, deleting your browser's site data will also clear the
Pedif library.

## Browser support

Pedif runs in any modern browser:

- **Chrome / Edge** — recommended
- **Safari** (macOS &amp; iOS) — recommended
- **Firefox**

The library needs IndexedDB and `localStorage`; if storage is unavailable, Pedif
still reads PDFs using an in-memory fallback (the library simply won't persist).

## Tips &amp; troubleshooting

- **Nothing happens when I open a URL.** Many servers block cross-origin requests
  (CORS). Download the PDF and open it locally instead.
- **The library is empty after clearing browser data.** The library lives in local
  browser storage, so clearing site data removes it.
- **Print does nothing on mobile.** Allow pop-ups for the page, or use
  *Download* and print from your PDF viewer.
- **Motion feels too much / too little.** Pedif follows your system
  *Reduce Motion* setting.
- **Right-to-left documents** render with correct text direction automatically.
